《生化危机4 重制版》宝物镶嵌优化工具 — 使用说明
=====================================================

一、如何启动
------------
1. 解压 RE4GemOptimizer.zip（右键 -> 全部解压缩，不要直接在压缩包里双击）。
2. 打开解压后的 RE4GemOptimizer 文件夹。
3. 双击 RE4GemOptimizer.exe。

无需安装 Python，也无需输入任何命令，直接就能打开中文窗口。

二、如何使用
------------
1. 在左栏「宝石库存」里填每种宝石你拥有的数量（0 也可以留空不填）。
   每行都有「−」和「+」按钮，也可以直接在中间输入框里键入、粘贴数字。
2. 在右栏「宝物库存」里填每种宝物你拥有的数量。
3. 在左栏下方选择优化目标：
   - 出售剩余宝石：最大化宝物售价＋剩余宝石单卖收入（默认）。
   - 保留剩余宝石：只最大化宝物售价，剩余宝石保留。
4. 点「生成镶嵌方案」按钮。
5. 稍等片刻，窗口下方会显示每件宝物的镶嵌方案、倍率、售价，以及总收益和剩余宝石。

提示：已经镶嵌在宝物上、且你愿意拆下来重新分配的宝石，也算进库存，
但同一颗宝石只计数一次。修改数量或切换优化目标后，旧结果会自动作废，
需要重新点「生成镶嵌方案」。

三、添加图片（可选）
--------------------
程序默认用文字占位图显示宝石和宝物。想显示真实图片时：

1. 在 RE4GemOptimizer 文件夹下，找到 assets 文件夹，
   里面有 gems 和 treasures 两个子文件夹。
2. 把图片按下面的英文名命名，放进对应文件夹（PNG 格式最佳）：

   宝石（放 assets/gems/）：
     ruby.png              红宝石
     sapphire.png          蓝宝石
     yellow_diamond.png    黄钻石
     emerald.png           祖母绿
     alexandrite.png       亚历山大石
     red_beryl.png         红色线柱石

   宝物（放 assets/treasures/）：
     flagon.png            酒壶
     splendid_bangle.png   华丽手镯
     elegant_bangle.png    典雅手镯
     elegant_mask.png      典雅面具
     butterfly_lamp.png    蝴蝶灯
     chalice_of_atonement.png  赎罪圣杯
     extravagant_clock.png 奢华座钟
     golden_lynx.png       黄金猞猁
     ornate_necklace.png   华丽项链
     elegant_crown.png     典雅皇冠

3. 放好图片后，重新打开程序即可看到图片，无需重新打包。
   没有图片或图片损坏时，程序会自动显示文字占位图，不影响使用。

四、常见问题
------------
问：输入负数或小数会怎样？
答：程序会拒绝这样的输入并提示，不会悄悄改掉你的数字。

问：点了「生成镶嵌方案」后窗口卡住了吗？
答：计算在后台进行，窗口不会卡死；计算期间按钮会变灰，完成后自动恢复。

问：结果显示「尚未证明最优」是什么意思？
答：在 30 秒时限内找到了可行方案但还没严格证明它是最优。程序会明确标注，
不会把可行方案当成最优方案。

问：为什么有的宝石没用完、有的槽位是空的？
答：这是全局优化的结果——把所有宝物和宝石放在一起算，空槽或剩余宝石
有时反而能让总收益更高。同形状槽位里具体放哪颗，位置可自行决定。
